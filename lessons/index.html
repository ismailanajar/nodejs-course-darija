خريطة الكورس: Node + React Fullstack

من architecture حتى dashboard — مرتبة على ترتيب الكورس المحلي، كل درس 10–15 دقيقة بquiz ديال retrieval.

ابدا من الدرس 1 حتى 20 · كل درس فيه رابط «الدرس السابق/الجاي»

Phase 1 — السيرفر و الـ auth (01–04)

  1. شكون كيتكلم مع شكون: Fullstack Architecture
  2. نشأو السيرفر: npm init و أول route handler
  3. Google OAuth و Passport JS: كيفاش كيمشي الـ flow
  4. MongoDB و Mongoose: connection + models + queries
  5. الـ session ديال authentication: passport callbacks + cookies + logout

Phase 2 — البيئة و الـ client (05–07)

  1. Dev vs Prod: keys و environment variables
  2. الـ Client: separate server و CRA proxy
  3. Redux و auth reducer: أول state ديالنا
  4. React Router و Header: التصفح و current user
  5. Redux Thunk و fetchUser: جلب currentUser و redirects

Phase 3 — الدفع، deploy، و data ديال survey (08–10)

  1. الدفع بـ Stripe: tokens و charges و credits
  2. فـ production: Express كيقدم الـ React build
  3. Mongoose ديال survey: subdocs و relationship fields
  4. الـ mailer: SendGrid و templates ديال survey

Phase 4 — الـ form، webhooks، و الـ dashboard (11–13)

  1. Redux Form: صياغة survey form بـ custom fields
  2. الـ validation و الـ wizard ديال form
  3. تصفيط survey للسيرفر و redirect
  4. Webhooks: ngrok و encoding ديال survey data
  5. من webhook لنتائج: lodash chain و mongoose queries
  6. الـ dashboard: جلب و عرض قائمة surveys
