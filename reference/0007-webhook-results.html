  • الـ webhook = سيرفر كيصيفط معطيات لسيرفر آخر حيت وقع حدث.[1] الـ SendGrid كيجمع الأحداث وكيصيفط bulk واحد كل 30 ثانية ولا دقيقة — فـreq.body array ديال objects.[2]
  • localhost:5000 عنوان خاص بالجهاز — الـ SendGrid خاصو URL عام: نهار ngrok http 5000 (خزّن الـ authtoken مرة وحدة)، ونهار https://your_app.herokuapp.com فالـ production. الـ ngrok address كتبدل مع كل restart فخاصك تعاود تبدّلها فـSendGrid.[3]
  • فين كتبدل: Settings → Mail Settings → Event Notification → HTTP POST URL = https://YOUR_HOST/api/surveys/webhooks (خاص الـ route كامل) + Test Your Integration.[4] الـ body اللي كيجي: array، كل عنصر عندو event، وclick فيه غير email + url.[5]
  • الـ SendGrid ما كيقبلش جوج webhook URL فحساب واحد — فمع كل deploy خاصك تعاود تشوف فين كيشير.[17]

4 · الاستفسار ديال التسجيل

Survey.updateOne(
  {
    _id: surveyId,                                            // ماشي id
    recipients: { $elemMatch: { email, responded: false } }   // vote واحد فقط
  },
  {
    $inc: { [choice]: 1 },                                    // yes + 1 ولا no + 1
    $set: { 'recipients.$.responded': true, lastResponded: new Date() }
  }
).exec();                                                     // خاصها exec()
  • ثلاث معايير: _id + recipient بنفس الـ email + responded: false — إلا صوّت من قبل، الـ criteria كتمشي والتسجيل كيتوقف.[11]
  • $inc = increment؛ الأقواس المربعة = key interpolation (ماشي array): قيمة choice كتولي اسم الـ property.[12]
  • recipients.$.responded — الـ $ كيشير لنفس العنصر اللي لقاه $elemMatch.[12]
  • كولشي كيتطبّق من داخل Mongo: ماشي find + تعديل يدوي + save() (اللي كتنقل الـ recipients كاملين جوج مرات).[11]
  • بلا async/await على الـ query: غير جاوب SendGrid بـ200 ونكمل.[13] وإلا ما جاوبتيش، غادي يعاود الـ event وتعاود تلقى الـ duplicates.[9]

5 · GET /api/surveys (الـ dashboard)

app.get('/api/surveys', requireLogin, async (req, res) => {
  const surveys = await Survey
    .find({ _user: req.user.id })
    .select({ recipients: false });     // whitelist
  res.send(surveys);
});

الـ response = array ديال objects (غير ديال المستعمل الحالي، و بلا الـ recipients):[14][15]

[{
  "_id": "...", "dateSent": "...", "lastResponded": "...",
  "yes": 49000, "no": 412,
  "subject": "...", "body": "...", "_user": "..."
}]
  • الترتيب: الأقدم فوق فالأصل — .reverse() قبل ما map باش الجديد يبان فوق.[18]
  • Redux: FETCH_SURVEYS + fetchSurveys() → surveysReducer (state الافتراضي array خاوية) → combineReducers → SurveyList و componentDidMount.[19][20]
