  • الـ client كاين فـ server/client/، وفيه server خاص بـ npm start على localhost:3000، و npm run dev (concurrently) كيشغّل جوج الخوادم مرة وحدة.[1][2]
  • الـ browser كيزيد domain ديالو على الروابط النسبية (= :3000 ماشي :5000) — علّاش خاص proxy: client/src/setupProxy.js بـ http-proxy-middleware@2، و CRA كيحمّلو بالسمية وحد.[3][4]
  • فـ production ما كاينش CRA server ولا proxy — الروابط النسبية كتمشي مباشرة لـ domain = نفس الـ Express.[5]
// client/src/setupProxy.js
const { createProxyMiddleware } = require('http-proxy-middleware');
module.exports = function (app) {
  app.use(['/api', '/auth/google'],
    createProxyMiddleware({ target: 'http://localhost:5000' }));
};

Redux data flow

componentcalls action creator
→
action / thunk{ type, payload }
→
dispatchfunnel → reducers
→
storestate → re-render
  • Vanilla rule: الـ action خاصو object فوري فيه type + payload.[10]
  • Redux Thunk (middleware مربوط فـ src/index.js): إلا الـ action creator رجّع function، كيناديها بـ dispatch — باش تسنى الـ API قبل ما تدير dispatch.[10]
  • combineReducers({ auth: authReducer }) → الـ key = مفتاح فـ state، يعني state.auth.[7]
  • الـ component كياخد state بـ connect(mapStateToProps)، و mapStateToProps({ auth }) كترجع الـ props اللي يحتاج.[6][11]

Router skeleton

  • BrowserRouter كيقبل child وحدة فقط — الـ routes كاملين داخل div وحدة، و Header فوقهم (component عادي ماشي route = كيبان دائما).[8][9]
  • exact على كل route — وإلا / كتغلب بـ greedy فـ /surveys وكتبان مزدوجة.[8]
  • <Link to> للتصفح الداخلي (React Router)، <a href> للخارج: OAuth /auth/google و logout /api/logout.[14]

  • Payload خاصو res.data غير (غير هو الـ user model)، و action.payload || false كيحوّل الـ string الخاوي لـ false.[11]
  • بعد login: passport.authenticate('google') من بعد handler ديال (req, res) => res.redirect('/surveys') — وإلا كيطيح error ماشي مفهوم.[12]
