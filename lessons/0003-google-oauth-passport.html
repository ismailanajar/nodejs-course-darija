Google OAuth و Passport JS: كيفاش كيمشي الـ flow

الـ login button الحمراء ديال "Sign in with Google" عندها وراءها مشيحة رايحة جاية بين browser وسيرفرنا و Google — وهنا غادي نفكّكو خطوة بخطوة.

~10 دقايق · Quiz ديال retrieval فالأخر

Win ديال هاد الدرس غادي تقدر تشرح لـclient كامل الـ OAuth flow: شكون بعت شكون، علاش خاص redirect URI مسجل، وفين كيجي الـ access token — وغادي تصاوب /auth/google ديالك بـ Passport بلا ما تتوهّن.

1 · البداية: أول feature

الكورس قال: أول حاجة غادي نبنيوها فهاد التطبيق هي الـ sign up بـ Google OAuth (خطوة 1 ديال الـ user flow اللي شفناها ف الدرس 1.1)، وعلاش هو التخصام ديال domain مخصص غادي نهضرو عليه من بعد.[1]

الـ diagram ديال الـ flow كيتقسم لـ ثلاث columns: Client، Server، Google — كل خطوة فيها كتبدا من شي column وتمشي لل الأخرى.[2]

2 · شنو كيدير Passport JS؟

Passport = helper library كتاخد علينا خطوات معينة من الـ flow (اللي فالـ diagram كيتعرضو بـ yellow box) بلا ما نكتبوا boilerplate بزاف.[3] بصح الكورس نبّه على مشتين كبار حول Passport: خاصك تعرف شنو بالضبط كيدير، وإلا ما غاديش تفهم كيفاش كيمشي.[3]

التنصيب:

npm install --save passport
npm install --save passport-google-oauth20

انتبه للـ 20 فآخر اسم الـ strategy — هادي النسخة ديالها.[4]

3 · options ديال الـ Google strategy

  • قبل ما تستعمل الـ strategy، خاصك ثنين ديال options: clientID و clientSecret، والجوج كيجيو من خدمة Google OAuth.[5]
  • clientID = public token — حتى شي مشكل إلا شي حد لوّلو؛ غير كيعرّف التطبيق عند Google.[6] أما clientSecret فخاصو يبقى مخفي كامل.[6]
  • الكورس كيحطهم فملف config/keys.js وكيزاد Prefix "Google" قدام كل key باش من بعد تزيد Facebook ولا LinkedIn وتبقى فاهم شنو شنو.[7]
  • تنبيه مهم بزاف: الـ key خاصها capital D (clientId) — الكورس طلب triple check حيت typo صغير كيسبب أخطاء صعيبة.[7]
  • عنّا callbackURL options: هادي هي الرابط اللي Google غادي يرجّع بيه الـ user من بعد ما يعطي الإذن.[7]

4 · كيفاش كيتجرّب الـ flow

الـ strategy كتاخد: أول argument = object ديال options، و الثاني = arrow function callback (غادي نهضرو عليها بالتفصيل ف الدرس الجاي).[8]

  1. الـ user كيحل /auth/google → السيرفر كيبعثو لـ Google.[8]
  2. الـ user كيختار حسابو ويسمح للتطبيق → Google كيرجّعو لـ localhost:5000/auth/google/callback.[8]
  3. أول مرة: غادي تشوف "Redirect URI Mismatch" — خاصك تسجّل الـ redirect URI عند Google (نفس الرابط بالضبط).[9]
  4. من بعد التسجيل: كتختار الحساب وتولّي "cannot get /auth/google/callback" — علاش؟ حيت مازال ما صاوبيناش الـ route handler ديال الـ callback.[10]
  5. الـ strategy كيشوف code اللي فالـ URL وكيدوز request تاني لـ Google باش يبدلو بـ profile ديال الـ user، ومن بعد كتنادي الـ callback وكيتبان access token فـ terminal.[11]

وخدمة صغيرة: الكورس نصب nodemon باش السيرفر يعاود يتشغل وحدي من كل تبديل ف الكود — بلا ما تدير Ctrl+C وnode index.js كل مرة.[12]

5 · ممارسة retrieval

جاوب من راسك قبل ما تحل شي حاجة. ما تقدرش تحل حتى تجاوب — هادي هي القوة اللي كتبني memory.

1. شنو كيدير Passport JS فهاد الـ flow؟

الـ Passport هو اللي كياخد علينا الخطوات اللي فالـ yellow box ديال الـ diagram بلا boilerplate بزاف.[3]

2. علاش خاص الـ redirect URI يكون مسجل عند Google؟

إلا ما سجلتيش نفس الرابط، Google كيرجعك بـ Redirect URI Mismatch — خاص الـ callback URL يكون مطابق تماماً.[9]

3. منين كيجي الـ client ID و client secret؟

الجوج كيتسلّمو ليك من خدمة Google OAuth نيشان: الـ clientID كيعرّف التطبيق، والـ clientSecret خاصو يبقى مخفي.[5][6]

4. مراجعة: شنو كيصاوب npm init؟

رجع للدرس 2: الـ npm init غير كيصاوب package.json، اللي هو الـ central hub ديال dependencies ديال المشروع.[13]
