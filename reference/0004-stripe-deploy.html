4 · production: server واحد كيقدم API + UI

if (process.env.NODE_ENV === 'production') {
  app.use(express.static('client/build'));          // 1) static files
  const path = require('path');
  app.get('*', (req, res) => {                      // 2) catch-all
    res.sendFile(path.resolve(__dirname, 'client', 'build', 'index.html'));
  });
}
  • الترتيب هو القانون: API routes → ملفات client/build → index.html (React router كتكفّل الـ path).[10]
  • Refresh على /surveys = full reload → السيرفر ما لقاش ملف → index.html → الـ client router.[11]
  • الـ build: cd client && npm run build — كل تبديل فـ src خاصو build جديد.[12]

5 · deploy & fixes

المشكلالحل
Deploy كيقدّم غير الـ Express (بلا UI)زيد client build step فالdeploy: "heroku-postbuild": "NPM_CONFIG_PRODUCTION=false npm install --prefix client && npm run build --prefix client".[13]
Render: build command = npm install فقطبدلو لـ npm install && npm run heroku-postbuild.[13]
Build fail بـ SyntaxError: Unexpected token / @hapiNode version mismatch: حيّد package-lock.json (client + server)، استعمل Node LTS، وطابق engines.[14]
/surveys كيرجع 404 فـ productionالـ catch-all ماشي فـ الـ if ديال NODE_ENV، ولا client/build ما مصاوبش.[10]
