1 · تشريح reduxForm({ ... })

OptionRole
form: 'surveyForm'Namespaces the values as state.form.surveyForm in the form reducer (one key per form, so many forms never collide).
validate: fnRuns on every submit attempt; empty errors object = valid.
destroyOnUnmount: falseKeep values when this component unmounts (default is true, values get dumped).
export default reduxForm({
  form: 'surveyForm',
  validate,
  destroyOnUnmount: false
})(SurveyForm);

3 · config array (DRY)

const FIELDS = [
  { label: 'Survey Title',   name: 'title' },
  { label: 'Subject Line',   name: 'subject' },
  { label: 'Email Body',     name: 'body' },
  { label: 'Recipient List', name: 'recipients' }
];

renderFields() {
  return _.map(FIELDS, ({ label, name }) => (
    <Field key={name} component={SurveyField} label={label} name={name} type="text" />
  ));
}
  • FIELDS lives above the component; key = name (unique + consistent).
  • Same array imported by SurveyFormReview for the review screen — one source of truth.
  • Add a field = one line in the array.

4 · validation function

function validate(values) {
  const errors = {};
  if (!values.title)    errors.title = 'You must provide a title';
  if (!validEmails(values.recipients)) errors.recipients = 'Invalid email in list';
  return errors;
}
  • Signature: values → errors. Empty object → submit proceeds; any key → submit blocked.
  • Error key must equal the field name; show it via meta.error + meta.touched inside the field component.
  • Email list: split(',') → trim → regex filter; use the HTML5 regex from emailregex.com (CRA linter warns on escaped patterns).
  • Error markup: <div class="red-text"> with margin-bottom: 20px.

7 · الـ submit pipeline

export const submitSurvey = (values, history) => async dispatch => {
  const res = await axios.post('/api/surveys', values);
  dispatch({ type: 'fetch_user', payload: res.data });  // refreshed credits
  history.push('/surveys');                              // programmatic redirect
};

// SurveyFormReview
export default connect(mapStateToProps, actions)(withRouter(SurveyFormReview));
  • onClick={() => submitSurvey(formValues, history)} — wrapping prevents instant execution at render.
  • withRouter(SurveyFormReview) (plain function call, unlike connect(...)(...)) puts history on props; newer react-router requires this hop.
  • Backend contract: request body key is recipients — keep client field names aligned.
