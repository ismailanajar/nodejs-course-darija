OAuth + Auth + Mongoose Flow

الـ authentication كامل فورقة واحدة — من زر Google حتى req.user وlogout.

Compressed from course sections 03–04 · Print this page

الـ OAuth Flow بالتفصيل

  1. الـ user كيحل /auth/google → السيرفر كيبعثو لـ Google.[1]
  2. الـ user كيختار حسابو ويسمح للتطبيق → Google كيرجّعو لـ callbackURL ديالنا (/auth/google/callback) وفيه code فالـ query string.[2]
  3. إلا ما سجلتيش نفس الرابط عند Google: Redirect URI Mismatch.[3]
  4. الـ strategy كيشوف الـ code وكيدوز request تاني لـ Google باش يبدلو بـ profile (+ access token).[4]
  5. الـ arrow callback (الـ argument الثاني ديال الـ strategy) كتنادي — فيها accessToken, refreshToken, profile.[5]
  6. الـ profile عندو Google user ID فريد → ن.query بيه فـ users، إلا لقينا نستعملوه، وإلا new User().save().[6][7]
  7. فالأخير: done(null, existingUser || newUser) → Passport كيكمل الباقي.[8]

req.userroute handler
  • الـ query asynchronous → promise → .then(existingUser => ...) — الـ قيمة يا instance يا null.[8]
  • بلا query، كل دخول كيزيد record جديد بنفس الـ Google ID.[7]
  • serializeUser كتنادي أوتوماتيكياً بالـ user model وكترجع user.id، وPassport كيحطها فالـ cookie.[14]
  • user.id = shortcut ديال _id ديال Mongo (ماشي profile ID) — حيت ممكن Facebook/LinkedIn وما عندوش Google ID.[14]
  • deserializeUser كتاخد الـ token من الـ cookie وكترجّع user model — راجع الإملاء، typo كيسبب "is not a function".[15]
  • Express ما عندها cookie support out of the box → npm install --save cookie-session وتنظمو فـ index.js.[16]
  • النتيجة النهائية: req.user فوق الـ request قبل ما يوصل للـ route handler — جربها مع GET /api/current_user.[17]

Logout

  • Route: GET /api/logout فـ authRoutes.[18]
  • req = request، res = response؛ Passport هو اللي كيزيد req.user ودوال خرين.[18]
  • req.logout() — كتاخد الـ ID اللي فالـ cookie وكتقتلو.[18]
