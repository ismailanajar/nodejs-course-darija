شكون كيتكلم مع شكون: Fullstack Architecture

قبل ما نكتبو سطر واحد ديال الكود، خاصنا نعرفو routing ديال الداتا فهاد التطبيق: browser → Express → MongoDB → يرجع.

~10 دقايق · Quiz ديال retrieval فالأخر

Win ديال هاد الدرس فـ10 دقايق، غادي تقدر تشرح لـclient (ولراسك) architecture ديال أي fullstack app: شكون كيخدم مع شكون، و علاش React عمرو ما كيتكلم مع MongoDB مباشرة. هادي هي المسالة اللي كتبدا بيها كل freelance project.

1 · اللي غادي نبنيو: Emaily

الكورس كامل = مشروع واحد اسمو Emaily: تطبيق ديال feedback collection.[1] الـ flow ديالو:[2]

  1. الـ product owner كيتسجل بـ Google OAuth (بلا email + password).
  2. كيشري credits بـ Stripe — كل survey كيصرف credit.
  3. كيصاوب survey (title, subject, recipients).
  4. الـ recipients كي clickaw على link فـ email وجاو بـ feedback.
  5. الـ feedback كيجي للسيرفر بـ webhook، وكيتسجل فـ DB.
  6. الـ owner كيشوف الـ results والرصيد ديال credits فـ dashboard.

2 · القاعدة ديال الـ architecture

فينما مشا الـ user لـ domain ديالنا، السيرفر كيرجع ليه HTML document + JavaScript files اللي فيهم الـ React app. هاد الـ React app هو اللي كيرسم الـ UI.[3]

أما المسالة الكبيرة: الـ React "ماعندو ما يورّي" بلا data — بغا يوري list ديال surveys؟ خاصو يسول على data من شي حد. وهنا جاي القانون ديال الكورس:

Law #1 الـ React NEVER كيتكلم مع MongoDB مباشرة. كلشي كيمشي فهاد الطريق: React → Express API → MongoDB. الـ Express هو الوسيط الوحيد بيناتهم.[3]

بأي مثال تخيّل MongoDB بحال أرشيف مغلق: Express هو الموظف اللي عندو المفاتيح، وReact كيبقى فالباب كيتسنى. كاع طلبات الداتا كيمشيو من عندو — حتى واحد ما كيدخل للأرشيف مباشرة.

دابا عندك backend experience — فهاد المشروع، الـ Express هو غير framework فوق الـ Node عطيك routing و middleware.[4]

3 · الـ route handler = watcher

كل ما كتبتي app.get('/api/surveys', ...)، كتسنا واحد route handler: الـ app object هو الـ server اللي خدام، و .get كتقول لـ Express "سنتيني requests بـ GET method". الـ HTTP methods غير conventions ديال intent: GET = جيب، POST = صيفط، PUT/PATCH = بدل، DELETE = مسح.[5]

شوف الـ round-trip ديال أي GET /api/surveys من الأول حتى للفين:

  1. Browser → Server GET /api/surveys
  2. Server → route handler match ديال المسار
  3. Express → MongoDB query ديال surveys
  4. MongoDB → Express records ديال results
  5. Express → Browser response فيها JSON

4 · ممارسة retrieval

جاوب من راسك قبل ما تclicki. ما تقدرش تحل حتى تجاوب — هادي هي القوة اللي كتبني memory.

1. فهاد التطبيق، منين React كياخد الداتا ديال الـ surveys؟

Law #1: الـ React كيسول غير لـ Express API. الـ MongoDB ماعندوش client — الـ Express هو الوحيد اللي كيقرا وكتب.[3]

2. شنو كيدير الـ server أول ما الـ user يحل الـ domain ديالنا؟

الـ Express كيرجع HTML + JavaScript files اللي فيهم الـ React app، وهادو كيتولّو فـ browser.[3]

3. فـ Express، شنو هو app.get('/api/surveys')؟

الـ app = server خدام؛ .get = route handler كيسنى incoming GET requests. الـ query ديال DB كيتصاوب من داخل الـ handler، ماشي هو الـ handler نفسو.[5]

4. package.json فهاد المشروع شنو هو؟

الـ npm init كيصاوب package.json، وهو الـ central hub ديال dependencies ديال المشروع.[4]
