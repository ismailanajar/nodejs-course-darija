Redux Form: صياغة survey form بـ custom fields

دابا السيرفر واجد وباقي غير الـ form: غادي نبنيو survey form بـ Redux Form، ونخرجولك الـ field component من config array بلا تكرار.

~12 دقايق · Quiz ديال retrieval فالأخر

Win ديال هاد الدرس غادي تقدر تصاوب أي form ديال client بـ Redux Form: الـ inputs كيتسجلو فـ Redux store بلا reducers مخصوصين، والـ fields كيتولدو من array وحدة ديال config — يعني تزيد field جديد فسطر واحد. هادي هي الطريقة اللي كتخدم بيها فـ freelance project بلا ما تعاود تكتب onChange handlers كل مرة.

1 · من السيرفر حتى للفورم

فـsections اللي فاتو، صاوبنا الـ route handler ديال POST /api/surveys عند الـ backend. ملي دابا واجد، الفورنت خاصو يعطي الـ user وسيلة باش يكتب الـ survey ديالو — وهادي هي النقطة اللي بدّل بيها الـ focus ديال الكورس للـ client side.[1]

أول حاجة كتبان للـ user هي الـ floating button ديال add فـ dashboard: كتصاوب بـ materializecss (fixed-action-btn)، بـ classes btn-floating btn-large red، وداخل <i class="material-icons">add</i>.[2]

ولكن الـ anchor العادي ماشي هو الطريق: كنبدلو بـ Link من react-router-dom، وكنديرو route /surveys/new اللي كيرسم الـ SurveyNew component.[2]

2 · شكون كيدير شنو: SurveyNew و SurveyForm

البنيان بسيط: SurveyNew هو container — هي اللي كتقرر واش نورّيو الـ form ولا الـ review. أما SurveyForm فيه الـ fields والـ labels وحدة بواحدة، وكل field عندها component خاص بيها.[3]

وإلا بدينا بلا Redux Form، خاصنا لكل input: onChange handler + action creator + reducer خاص + connect و mapStateToProps. هادي هي العركة اللي كيجيبها Redux Form: كيتولّى على كامل هاد الشي.[4]

بأي مثال بلا Redux Form، كل input كيسجّل فكراسو خاص بيه: onChange و reducer و connect ديالو هو بوحدهو، ومن بعد خاصك تجمع هاد الدفاتر بيدك. مع Redux Form فين كراسو وحدة هي الـ store ديال reduxForm()، وكل Field غير كيدوّز ليه القيمة مع input و meta. 
npm install redux-form --legacy-peer-deps   # مهم: بلا هاد الـ flag كيعطيك peer deps errors

ملاحظة الـ installation جات فملف HTML خاص بالدرس، والتوثيق ديال Redux Form (redux-form.com) موصى بيه بزاف.[5]

الاستعمال الأول هو جوج تاجات: reduxForm({ form: 'surveyForm' }) اللي كيلبس الـ component، و<Field> اللي كيمثّل كل input. الـ form: 'surveyForm' هو اسم الـ slice اللي غادي يسكن فيه الـ values فـ Redux store.[6]

3 · من HTML field حتى custom component

الـ Field كتقدر تعطيه component prop ديال الـ component ديالك هي. Redux Form من بعد كيصيفط ليه جوج props: input (الـ props ديال input: name, value, onChange…) و meta (الـ حالة: touched, error…). يعني الـ component ديالك كيركّز غير على الشكل، والبيانات كيجيوه من البار.[7]

  1. Field → SurveyField كيصيفط input و meta و label
  2. SurveyField → input كيرسم الخانة بـ value و onChange
  3. input → Redux store كل حرفة كتسجل فـ state.form.surveyForm
  4. Redux store → Field القيمة كترجع للعرض بلا handlers

ولكن بلا ما تكتب النص ديال label ميت فـ JSX، تعطيه label prop من برا، وهكذا كتقدر تستعمل نفس الـ SurveyField أربع مرات مع labels مختلفة.[8]

<Field component={SurveyField} name="title" label="Survey Title" type="text" />

4 · DRY: fields كاملة من config array

النتيجة: أربع حقول بنفس الـ props تقريبا — تكرار خالص. الحل ديال الكورس: تصاوب array وحدة فوق الـ component كتمثّل الـ fields كاملة (كل عنصر فيه غير label و name)، ومن بعد تloop عليها بـ _.map ديال Lodash وتخرج لكل عنصر Field وحدة.[9]

const FIELDS = [
  { label: 'Survey Title',   name: 'title' },
  { label: 'Subject Line',   name: 'subject' },
  { label: 'Email Body',     name: 'body' },
  { label: 'Recipient List', name: 'emails' }
];

renderFields() {
  return _.map(FIELDS, ({ label, name }) => (
    <Field key={name} component={SurveyField} label={label} name={name} type="text" />
  ));
}

فقط لا تنسى الـ key (React كيخلصك بـ warning ديال list بلا key، وname هو الأنسب حيت unique بين الـ fields).[9] وهكذا زادت field جديد = سطر واحد فوق — لا JSX جديد لا نسخ ديال props.[9]

FIELDS arrayسطر واحد لكل حقل: غير label و name
_.map + Fieldكتصاوب Field وحدة لكل عنصر بـ key
SurveyFieldالـ component ديال الشكل، نفسو كيتكرر 4 مرات
input / metaRedux Form كيصيفطهم بلا ما تكتب handlers
نتيجة كتجي غلط درتي جوج fields بنفس الـ name ولا نسيتي الـ key: الـ values كيتخلطو والـ React كيعطي warning ديال list. الحل: كل عنصر فـ FIELDS عندو name وحيد ودوزو كـ key للـ Field.

5 · ممارسة retrieval

جاوب من راسك قبل ما تclicki. ما تقدرش تحل حتى تجاوب — هادي هي القوة اللي كتبني memory.

1. شنو عندو الـ component اللي كتكتب مع reduxForm() و Field؟

Redux Form كيتولّى على تسجيل الـ values فـ store ديالو — بلا reducer خاص وبلا POST آلي: الـ POST غادي نصاوبوه يدوي فـ الدرس 17.[6]

2. مراجعة: من الدرس 1.1، React شكون كيسيلو ملي كيحتاج data ديال surveys؟

Law #1: الـ React كيسول غير لـ Express API، والـ MongoDB ما عندهاش client. حتى الـ form values غادي تصدي للسيرفر من نفس الطريق.[1]

3. شنو كيدير Field بـ component={SurveyField} prop؟

Redux Form كيصيفط input و meta props للـ component اللي تعطيه؛ أما الـ label فكتعطيه إنت كـ prop.[7]

4. علاش لقّينا الـ fields فـ array اسمو FIELDS قبل ما نصايبو الـ component؟

الـ array هي الـ config: كل field = object فيه label و name فقط، و_.map كتصاوب منو الـ Field components.[9]
