نشأو السيرفر: npm init و أول route handler

من directory خاوية حتى لـ localhost:5000 اللي كيرجع ليك شي حاجة — هادي هي الوحدة اللي كتبدا بيها أي backend project.

~10 دقايق · Quiz ديال retrieval فالأخر

Win ديال هاد الدرس غادي تصاوب server جديد من الصفر (npm init → install Express → أول app.get) وتوصل بيه من browser، وغادي تقدر تشرح لـclient شكون كيسمع للـ traffic وشكون كيقرر كيفاش يجاوب — Node ولا Express.

0 · رجع سريع

الدرس اللي فات قلنا القانون ديال المشروع: React كيسول غير لـ Express API، والExpress هو اللي كيقرا من MongoDB.[1] دابا غادي نبنيو نفس هاد الـ Express API بوحدو.

1 · من الصفر إلى package.json

الأوامر كاملة كتمشي فـ terminal:

mkdir Server && cd Server
npm init
npm install --save express
  • npm init كيسولك شي أسئلة — الكورس كيجاوب بالـ default values (enter, enter, enter).[2]
  • النتيجة هي package.json، اللي الكورس كيناديه central hub ديال المشروع و فينو كيتسجلو الـ dependencies.[2]
  • من بعد npm install --save express، كتلقى express مسجل فـ dependencies، وnode_modules فيه Express نفسو مع dependencies ديالو.[2][5]

2 · Node ولا Express؟

الكورس عطى تعريفات واضحة:[3]

  • Node = JavaScript runtime كيexecute الكود خارج الـ browser، وهو اللي كيسمع الـ HTTP traffic على port واحد (الـ port كيشبه لباب دخل منو الـ requests).
  • Express = ماشي runtime بوحدو — هادي library ديال helpers فوق Node باش كتابة السيرفرات تبقى ساهلة. كلشي اللي كيدير Express، تقدر تصاوبو بـ Node عادي.

يعني: Node هو اللي كيتحمّل الـ traffic الحقيقي، Express هو اللي كيقول "هاد الـ request هادي خاصها هاد الـ handler".[3]

3 · أول route handler

فـ server directory، كنصاوبو index.js — الـ convention ديال startup file فـ Node projects.[4]

const express = require('express');
const app = express();

app.get('/api/current_user', (req, res) => {
  res.send({ hi: 'there' });
});

app.listen(5000);
  • require = CommonJS modules، النظام اللي Node كيستعملو لمشاركة الكود بين files (ماشي import ديال ES2015 — الـ React side هو اللي كيستعملو).[4]
  • const app = express() = كتصاوب تطبيق Express واحد خدام.[4]
  • app.get(...) = route handler جديد كيسنى incoming requests بـ HTTP GET. الـ app نفسو هو الـ server الخدام.[6]
  • بجانب get عندينا post، put، patch، delete — الـ methods غير معنى نوع الـ request.[6]
  • app.listen(5000) وبعدها كتحل localhost:5000 فـ browser.[4]

هاد الدرس كامل كيتجمع فهاد الـ sequence ديال الخمس خطوات:

  1. mkdir Server && cd Server directory جديدة للمشروع.
  2. npm init كيصاوب package.json — الـ central hub ديال dependencies.
  3. npm install --save express كينصب Express ويسجلو تحت dependencies.
  4. index.js كتب require(express)، وحد app.get(...)، ومن بعد app.listen(5000).
  5. localhost:5000 كتحل فـ browser وكيجاوبك أول route handler.
نتيجة كتجي غلط من أول تشغيل ديال السيرفر، إلا كتبتي import express from 'express' بحال الـ React side، فـ terminal غادي تشوف SyntaxError: Cannot use import statement outside a module. الحل: فـ index.js ديال Node استعمل require — هادا هو نظام CommonJS اللي كيستعملو الـ backend.

4 · تفاصيل صغيرة كتفرق

  • الكورس كيستعمل atom . باش يحل الـ editor من داخل الـ directory — إلا ما عندكش Atom، حل editor ديالك يدوي.[5]
  • package-lock.json ماكيبانش إلا كنتي على npm 5 على الأقل — والكورس باغي هاد النسخة حيت غير محتاج ميزات منها.[5]
  • الكورس كيدير deploy بكري بزاف: حتى مع هاد الكود البسيط، غادي نتعلمو الـ deployment مع Heroku (service خارجي اللي كتبدا بيه بلا credit card) باشصحابك و عائلتك يجربو التطبيق.[7]

5 · ممارسة retrieval

جاوب من راسك قبل ما تحل شي حاجة. ما تقدرش تحل حتى تجاوب — هادي هي القوة اللي كتبني memory.

1. شنو كيصاوب npm init فالمشروع؟

الـ npm init كيصاوب package.json، اللي هو الـ central hub ديال المشروع و فيه الـ dependencies.[2]

2. شنو كيبان فـ package.json من بعد ما نصبنا Express؟

من بعد npm install --save express، Express كيبان مسجل تحت dependencies، وكاع ملفاتو داخل node_modules.[2]

3. شنو كيدير السطر app.get('/api/x', ...)؟

الـ app هو الـ server الخدام، و.get كتخلق route handler جديد كيراقب incoming HTTP GET requests.[6]

4. مراجعة: فهاد الكورس، شنو القانون ديال relationship بين React و MongoDB؟

Law #1 ديال الدرس 1.1: React عمرو ما كيتكلم مع MongoDB مباشرة — الطريق كاملة كتمشي من خلال Express API.[1]
